Documentation

Everything you need to go from an empty folder to a lineup of live channels.

Overview

tvmanager reads your media from Plex, Jellyfin, Emby or folders on disk, lets you build channels in a web dashboard, and serves them as live TV:

  • Always on air. Each channel plans about 48 hours ahead from the wall clock, so it is "broadcasting" even when nobody watches. When someone tunes in, playback starts at the right point in whatever is on.
  • On-demand encoding. ffmpeg only runs for channels someone is watching, and stops shortly after the last viewer leaves.
  • Gapless. Each programme, ad and card is encoded separately and spliced into one continuous stream.

You can watch in IPTV apps (M3U playlist and XMLTV guide), in Plex (as a network tuner), or in any browser.

Install

Requirements

  • Node.js 22 or newer.
  • ffmpeg and ffprobe, a full build that includes the drawtext filter (on Windows, the gyan.dev "full" build). Put them on your PATH, or set their paths in config.json.
  • Tested on Windows. Linux and macOS should work, but set the font paths (see configuration).

Steps

git clone https://github.com/weareleon/tvmanager.git
cd tvmanager
npm install
npm start

tvmanager starts on port 8420 and creates an empty config.json on first run. Open http://localhost:8420. If ffmpeg can't be found, the server log says so and tells you how to fix it.

The default port is 8420 so tvmanager can run next to ErsatzTV, which uses 8409.

First run

The first time you open the dashboard it asks you to create an account.

  • On the tvmanager PC itself, a username and password are all you need.
  • From another device, or through a reverse proxy, you also need the 6-digit setup code printed in the server log. That stops anyone else on your network from claiming the server before you do.

Then add things in this order: a media source, a collection, and a channel.

Media sources

Add sources under Media sources → Add source. A scan starts straight away, and the source's card shows how many items it found or what went wrong.

Plex

  1. Choose Plex and click Sign in with Plex.
  2. Approve tvmanager in the Plex window that opens. This is Plex's own sign-in, so your password never reaches tvmanager.
  3. Pick a server. tvmanager connects to the first address that answers: this PC, then your network, then remote, then Plex's relay.
  4. Tick the libraries to import and click Save.

Jellyfin and Emby

  1. Create an API key. In Jellyfin: Dashboard → API Keys → +. In Emby: Settings → Advanced → API Keys.
  2. Choose Jellyfin or Emby, enter the server URL (e.g. http://localhost:8096) and the key.
  3. Click Test connection, tick the libraries and save.

Local folders

Choose Local folders and enter one folder per line. Subfolders are included. Files are probed with ffprobe, and names like Show Name - S01E02 - Title.mkv are read as episodes.

Docker, NAS and other machines

tvmanager reads a file directly when this PC can see it, and otherwise streams the original file from the server, with no transcoding. If the server sees files at different paths (for example /media/... inside Docker), open Advanced and add path replacements like /media => \\nas\media, or set playback to Always stream from the server.

Plex tokens and API keys are only added to stream URLs at play time. They never reach the browser, are redacted from logs, and are never written to data/.

Collections

A collection is a group of media for channels to play from, like "all episodes of one show" or "every comedy movie". Under Collections → New collection, pick a source and filter it:

FilterWhat it does
LibraryOnly items from one library (media servers).
TypeMovies, episodes or other videos.
ShowsOnly these shows. A searchable list with episode counts.
GenresItems with any of the selected genres.
FolderOnly files under a folder (local sources).
Path containsOnly files whose path contains some text, e.g. Christmas.

The preview on the right shows how many items match, their total runtime, and the order they will play in. Shows play in season and episode order.

Channels

Create a channel under Channels → New channel. The editor has these sections:

  • Basics: name, number, group and logo URL, as shown in the guide and TV apps.
  • Programming: what plays when no schedule block is active (a collection in order or shuffled, a live restream, or nothing), and an optional gap filler collection of short clips.
  • Ad breaks, Weekly schedule, Special events, Watermark and On-screen graphics, all described below.
  • Coming up: the real timeline for the next 12 hours, updated when you save.

Changes apply immediately. A channel that is being watched picks them up from its next programme.

Scheduling

Weekly blocks

Add a block, give it a name, pick days and start and end times, and choose what it plays. A block that ends earlier than it starts runs past midnight. The week grid shows every block, and clicking one jumps to its settings.

Special events

Special events are blocks on one date, like New Year's Eve. They beat weekly blocks when they overlap. Each block has a priority if you need finer control: events default to 100, weekly blocks to 10, and the higher number wins.

Hard starts

Blocks start exactly on time. If the next programme won't fit before a block begins, the gap is filled with clips from the channel's gap filler, then an "Up next" screen for whatever is left.

Live restreams

A block can play a live stream instead of a collection: either a direct stream URL, or an M3U playlist plus the channel to pick from it (matched by tvg-id, tvg-name or display name).

Commercial breaks

A break style is an ordered list of slots, built under Breaks:

  • Clips from a collection, either a number of clips or "up to N seconds" of them. Use these for ads, promos and bumpers. Clips are picked at random without repeating until the collection runs out.
  • "Up next" cards: a lower-third with the next programme's title, episode and start time, over a plain backdrop or a looping background clip. In a mid-roll break the card says "Back to …".

In a channel's Ad breaks section, pick a style and where it goes:

  • Between programmes.
  • Mid-roll: every N minutes inside programmes longer than M minutes. Cuts snap to the file's chapter markers when it has them, which usually fall on scene changes.

Breaks never push a scheduled block late. Near a block boundary they are shortened or skipped, and a programme drops its mid-roll if that's what it takes to fit. The TV guide shows each programme as one entry, with its breaks included.

Graphics and watermark

Graphics are drawn live by the encoder, so they cost almost nothing and appear at the right moment even when you tune in mid-programme. Add them in a channel's On-screen graphics section, which has a live animated preview:

GraphicWhat it does
Up next bannerSlides in a set number of seconds before a programme ends, with what's on next and when.
Now playing bannerShows the programme's title shortly after it starts.
CountdownTicks down to the channel's next special event, or to a date and time you pick, then shows ON NOW.
TickerScrolling text along the bottom, with an optional tag like "TONIGHT".
ClockThe current time in a corner, 24-hour or 12-hour.

Each graphic can show during programmes only, or during everything including breaks. The accent colour styles every graphic and the break cards.

Watermark

Upload a logo (a PNG with transparency works best), then set its corner, size, opacity and distance from the edge. Animations: fade in and out with each programme, a gentle pulse, or slide in. Animated GIFs play as they are. Set Show during to Programmes only to hide the logo during breaks.

IPTV apps

Add these two URLs to your app (replace your-pc with this PC's address):

http://your-pc:8420/iptv/channels.m3u
http://your-pc:8420/iptv/xmltv.xml
  • Jellyfin: Dashboard → Live TV → Tuner devices → M3U Tuner, then add the XMLTV guide under TV guide data providers.
  • TiVimate, Kodi (IPTV Simple Client), VLC and other M3U players work the same way.

Plex Live TV

Plex doesn't accept M3U playlists, so tvmanager also acts as an HDHomeRun network tuner:

  1. In Plex, open Settings → Live TV & DVR → Set up Plex DVR.
  2. If tvmanager isn't listed, choose enter its network address manually and enter http://your-pc:8420.
  3. For the guide, choose the XMLTV option and enter http://your-pc:8420/iptv/xmltv.xml.
  4. Plex matches each channel to its guide entry by number. Check the matches and finish.

The tuner advertises 4 simultaneous streams by default (server.tuners). Tested with Plex Media Server 1.43.

In a browser

Anyone on your network can watch at http://your-pc:8420/watch, with no app and no sign-in:

  • Channel grid: what's on now, with progress, and what's next.
  • Player: live video, a now/next panel, the upcoming guide and a channel list. ↑ ↓ change channel, M mutes, F goes fullscreen.

It works in Chrome, Edge and Firefox (desktop and Android), and in Safari on iPhone and iPad using HLS. Browsers start videos muted until you tap to unmute. To turn the page off, set "server": { "publicWatch": false }.

HLS

Every channel is also available as HLS at /hls/<number>/index.m3u8, and /iptv/channels.m3u?format=hls is a playlist that uses those URLs. The first request starts a segmenter that copies the channel's stream into 4-second segments without re-encoding (the first playlist takes a few seconds). It stops about 45 seconds after the last request.

Encoding

Under Settings → Encoding, tvmanager runs a short test encode with each encoder to show what works on your PC and how fast:

EncoderHardware
Software (x264)Any CPU.
NVIDIA (NVENC)GeForce, RTX and Quadro graphics cards.
Intel (Quick Sync)Intel CPUs with integrated graphics, and Arc cards.
AMD (AMF)Radeon graphics cards and Ryzen APUs.

You also set the resolution (480p, 720p or 1080p), frame rate, and video and audio bitrates. Changes apply to each channel the next time it starts, so a stream in progress is never interrupted. A graphics card encoder takes the load off the CPU, so more channels can run at once.

Users and security

  • What needs a sign-in: the dashboard and its API. The playlist, guide, streams, HLS, the Plex tuner and the browser TV page stay open, because TV apps can't sign in. Anyone who can reach port 8420 can watch, so don't expose it to the internet unless you mean to.
  • Settings: change your password (this signs out your other devices), add or remove users, and sign out other devices.
  • Under the hood: passwords are hashed with scrypt. Sessions are HttpOnly, SameSite cookies that last 30 days and renew while in use. Changes require a custom request header (CSRF protection). Sign-in locks for 15 minutes after 10 failed attempts.
  • Where credentials live: data/auth.json, never config.json.

Locked out

On the tvmanager PC, run this. It prints a new password and signs that user out everywhere. Restart tvmanager afterwards.

npm run reset-password -- <username>

Everything you set in the dashboard is saved to config.json. These settings are only available in the file. Restart after changing them.

Troubleshooting

"ffmpeg not found" in the log

Install a full ffmpeg build and add it to your PATH, or set "ffmpeg": { "ffmpeg": "C:/ffmpeg/bin/ffmpeg.exe", "ffprobe": "C:/ffmpeg/bin/ffprobe.exe" } in config.json.

A source shows "the server rejected the API key"

The key was deleted or mistyped. For Plex, click Sign in again in the source's editor.

A collection has 0 items

Check its filters in the preview, and that the source finished scanning (see its card under Media sources).

Graphics or slate text don't appear

Your ffmpeg build lacks drawtext, or the font files don't exist. Use a "full" ffmpeg build and check the font paths in the configuration.

Other devices can't connect

Use this PC's network address rather than localhost, and allow port 8420 through the firewall.

Stuttering with several channels at once

Switch to a graphics card encoder under Settings → Encoding, or lower the resolution.

Still stuck? Open an issue with the server log.
